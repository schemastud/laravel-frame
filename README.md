# schemastud/laravel-frame

Frame's Laravel resource registry and generic manifest/resource socket pair with `@schemastud/frame`.
A producer supplies its resource declarations, read/write handlers and authorization integration.

See [write forms and read schemas](docs/resource-schemas.md) for the declared purpose selector,
configured generator, resolver, compatibility and frontend contract. Existing owning decisions are
under [docs/adr](docs/adr). Run the package's `composer test` with its development dependencies.
